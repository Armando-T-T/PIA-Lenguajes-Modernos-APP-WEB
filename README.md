# PIA-LM
# Descripción del proyecto
El proyecto “APP WEB – Reseñas de Películas” es una aplicación web desarrollada en el marco de la materia de Lenguajes Modernos. Su objetivo es proporcionar una plataforma donde los usuarios puedan:
-- Consultar películas disponibles en la base de datos.
-- Leer reseñas y valoraciones realizadas por otros usuarios.
-- Crear sus propias reseñas y puntuaciones sobre las películas.
-- Generar un espacio de interacción que fomente el intercambio de opiniones sobre el cine.
Este proyecto combina conceptos de desarrollo web frontend y backend, integrando tecnologías modernas para ofrecer una experiencia de usuario sencilla, intuitiva y funcional.

# Instrucciones de compilación y uso
1. Requisitos previos
Antes de compilar y ejecutar el proyecto, asegúrate de tener instalado:
Node.js
 (versión recomendada LTS).
Un gestor de dependencias como npm o yarn.
Un editor de código (por ejemplo, Visual Studio Code).

2. Instalación del proyecto
Descarga y descomprime el archivo ZIP del proyecto.
Abre una terminal dentro de la carpeta principal del proyecto.
Ejecuta el comando:
npm install
Esto instalará todas las dependencias necesarias.

3. Ejecución en entorno local
Una vez instaladas las dependencias, inicia el servidor de desarrollo con:
npm start
Esto levantará el proyecto en un servidor local, normalmente accesible desde:
http://localhost:3000/

4. Uso del sistema
Accede desde tu navegador al servidor local.
Explora las películas disponibles en el catálogo.
Regístrate o inicia sesión (si está implementado) para poder publicar reseñas.
Crea reseñas, asigna calificaciones y consulta las opiniones de otros usuarios.
